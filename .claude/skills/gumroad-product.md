# Skill: Gumroad Product Builder

## Uso
Quando l'utente chiede di creare o migliorare un prodotto digitale, lavora sui file in `module-1-digital/`.

## File principali
- `module-1-digital/landing-page.html` — pagina di vendita (deve contenere `gumroad.com`, NO `YOUR-PRODUCT-LINK`)
- `module-1-digital/notion-template-spec.md` — spec interna del template

## Checklist landing page
- [ ] H1 con benefit principale (non feature)
- [ ] Social proof o "creato da uno sviluppatore"
- [ ] Prezzo visibile (non nascosto)
- [ ] CTA principale above the fold
- [ ] Garanzia soddisfatti o rimborsati
- [ ] Link Gumroad reale: `https://expressanswer.gumroad.com/l/SLUG`
- [ ] Sezione features con 4-6 card
- [ ] Footer con link Gumroad

## Pricing consigliato
- Template base: €9 (pay what you want, min €9)
- Bundle Pro: €24
- Aggiornamenti gratuiti a vita per chi acquista

## Copy framework (AIDA)
1. **Attention**: problema che il developer ha ogni giorno
2. **Interest**: soluzione specifica con dettagli tecnici
3. **Desire**: come cambia il workflow dopo l'acquisto
4. **Action**: CTA con garanzia per ridurre rischio
